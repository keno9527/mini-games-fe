# 斗兽棋产品设计

游戏标识：`animal-chess`。状态：当前实现说明；核对日期：2026-09-30。

面向产品讨论、功能变更与回归评审。以下规则来自现有入口、实现及已列出的测试定义；定位是对当前玩法的概括，不代表已确认的用户研究或历史设计动机。

## 定位与体验

本机两人轮流操作的策略棋类游戏。赤方先行，通过棋子强弱与河流、陷阱、兽穴争夺胜利；当前入口没有人机模式。

## 棋盘与行棋

棋盘为 7 列 × 9 行，双方各有八种动物。通常每步沿上下左右移动一格，点击己方棋子显示合法落点，再点击落点移动或吃子。

| 规则     | 当前行为                                                             |
| -------- | -------------------------------------------------------------------- |
| 强弱     | 象、狮、虎、豹、狼、狗、猫、鼠依次递减，通常可吃同级或更弱棋子       |
| 鼠象特例 | 鼠可吃象，象不能吃鼠                                                 |
| 河流     | 只有鼠能进入；鼠不能跨水岸吃子；狮虎可越过河道，路径中的鼠会阻挡跳跃 |
| 陷阱     | 进入对方陷阱的动物失去原有战斗等级，吃子规则受陷阱归属影响           |
| 兽穴     | 不能进入己方兽穴；进入对方兽穴获胜                                   |

## 胜负与反馈

占领对方兽穴、吃光对方棋子，或让对方无合法着法，均可获胜。页面展示当前行棋方、双方剩余棋子和已行步数，标记最近一步；结束后不能继续落子，可重新开局。

## 记录与边界

对局结束向当前玩家提交 100 分的完成记录，未将赤方或青方胜负映射为当前玩家的胜负，也没有为两位参与者分别建立成绩。当前没有对局存档、悔棋或重复局面和棋裁定入口。

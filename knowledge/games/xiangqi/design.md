# 中国象棋 · 残局闯关产品设计

游戏标识：`xiangqi`。状态：当前实现说明；核对日期：2026-09-30。

面向产品讨论、功能变更与回归评审。以下规则来自现有入口、实现及已列出的测试定义；定位是对当前玩法的概括，不代表已确认的用户研究或历史设计动机。

## 定位与体验

执红先行，在限定红方步数内破解残局。当前是 6 章 30 关的单人残局挑战，不是完整开局对弈或本机双人模式。

## 对局规则

使用象棋合法行棋规则，包括蹩马腿、塞象眼、炮架、过河兵、九宫与将帅照面限制；被将军必须应将，不能让己方将帅暴露在攻击中。将死或困毙黑方均获胜，不以“吃掉将帅”作为合法落子。

| 场景     | 当前行为                                                                   |
| -------- | -------------------------------------------------------------------------- |
| 步数目标 | 各关要求 2–8 次红方落子内取胜；黑方应对不计入步数                          |
| 黑方应对 | 自动选择抵抗着法；错误进攻可能让黑方逃脱或反将死                           |
| 失败     | 耗尽步数仍未取胜，或红方被黑方将死等终局失败                               |
| 提示     | 从当前局面推演可行走法；未求得可靠结果时明确提示，不把搜索不足当成确定无解 |
| 悔棋     | 回退整个回合，包括黑方思考期间的回退                                       |
| 重试     | 重建本关残局，允许再次争取更高星级                                         |

## 评价与进度

独立完成获 3 星；使用提示、使用悔棋分别减 1 星，最低 1 星。胜利按星数 × 100 计分，失败为 0 分；胜负均有结算。通关顺序解锁后续关卡，按玩家保留最佳星级。

## 产品边界

这是有步数上限的残局求解，不采用长局重复局面裁定。章节用于组织学习难度，具体棋局和步数目标由关卡配置定义。

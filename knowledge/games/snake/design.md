# 贪吃蛇产品设计

游戏标识：`snake`。状态：当前实现说明；核对日期：2026-09-30。

面向产品讨论、功能变更与回归评审。以下规则来自现有入口、实现及已列出的测试定义；定位是对当前玩法的概括，不代表已确认的用户研究或历史设计动机。

## 定位与体验

机关路线闯关：规划蛇身移动顺序，吃齐苹果后抵达出口，并可挑战额外宝石收集。当前入口是九关机关花园，不是无限随机食物的经典生存模式。

## 关卡与流程

三章为路线入门、钥匙花园、传送奇遇，共 9 关。开始有倒计时，蛇按固定节奏前进；玩家控制转向，可暂停、重试及选择已解锁关卡。切到后台会暂停。

| 元素     | 当前规则                                                       |
| -------- | -------------------------------------------------------------- |
| 苹果     | 吃到后增长蛇身；全部收集后出口才满足通关条件                   |
| 出口     | 必须带着已完成的苹果目标走到出口，收齐苹果本身不会直接结束本关 |
| 钥匙与门 | 对应钥匙打开对应门；钥匙不增长蛇身，撞上未开的门失败           |
| 传送门   | 从入口转移到配对出口，保持方向；出口被蛇身占用仍会碰撞失败     |
| 宝石     | 可选收集，不增长蛇身，不影响下一关解锁                         |
| 碰撞     | 撞墙、身体或当前仍占用的尾格失败；不能直接反向掉头             |

## 进度与成绩

通关逐关解锁，保留宝石收集结果和最佳移动步数；再次以较差成绩通关不会抹掉最佳记录。每吃一个苹果计 10 分，成功或失败均按本次关卡尝试结算；关卡进度按玩家保存。

## 产品边界

关卡重试从初始盘面开始，没有蛇身位置的中途续玩。宝石是重复挑战目标，而不是强制通关门槛；进度保存失败时有重试保存提示。

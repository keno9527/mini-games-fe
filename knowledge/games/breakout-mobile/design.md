# 打砖块（手机端）产品设计

游戏标识：`breakout-mobile`。状态：当前实现说明；核对日期：2026-09-30。

面向产品讨论、功能变更与回归评审。以下规则来自现有入口、实现及已列出的测试定义；定位是对当前玩法的概括，不代表已确认的用户研究或历史设计动机。

## 定位与体验

面向手机竖屏与拇指操作的独立打砖块入口，免登录，进度保存在当前浏览器。复用桌面版 30 个关卡布局，但使用独立运行与存档流程。

## 操作与流程

| 场景       | 当前行为                                                                             |
| ---------- | ------------------------------------------------------------------------------------ |
| 移动       | 手指相对滑动控制挡板；按下时不让挡板瞬移，也不直接发球                               |
| 发球       | 单独点击发球动作；丢球后回到待发球状态                                               |
| 暂停与离开 | 提供暂停、继续、重试与选关；挑战开始后，重试、切关或返回首页会出现确认               |
| 方向和设备 | 手机使用竖屏游戏；横屏由运行时处理暂停和方向提示；桌面精细指针设备进入手机试玩入口页 |
| 设置       | 可调整声音开关和音量，设置写入浏览器存档                                             |

## 玩法规则

初始 3 条生命；清除全部可破坏砖块过关，所有球丢失扣生命，耗尽则失败。包含加宽、多球、自动激光、减速、穿透、额外生命六类道具；激光无需额外开火按钮。丢球清除效果，暂停冻结物理和效果时间。

## 进度与记录

浏览器存档保存最近关卡、最高分、音频设置；刷新后从保存关卡的待发球状态开始，不恢复此前球的位置、生命或整局分数。完成关卡保存后续关卡，最后一关保持在有效范围内。

该入口不接入玩家文件战绩；不同浏览器不会自动同步，也不会读写桌面版自定义关卡或玩家进度。损坏的旧存档保持原样，页面提示当前进度仅在本页有效；存储失败不阻止继续游戏。

## 产品边界

当前入口没有桌面版关卡编辑器。共享关卡布局不代表两端存档互通；桌面入口、手机访问与分享能力以各自页面为准。

# 扫雷产品设计

游戏标识：`minesweeper`。状态：当前实现说明；核对日期：2026-09-30。

面向产品讨论、功能变更与回归评审。以下规则来自现有入口、实现及已列出的测试定义；定位是对当前玩法的概括，不代表已确认的用户研究或历史设计动机。

## 定位与体验

以数字推理为核心的固定盘面学习闯关。当前入口是四章二十关逻辑挑战，不是随机雷区难度选择。

## 关卡与核心规则

章节依次为看懂数字、线索之间、纵观全局、新的线索，每章 5 关。数字表示周围八格雷数，逐步引入线索组合、全局与区域推理。

| 场景     | 当前行为                                                   |
| -------- | ---------------------------------------------------------- |
| 揭格     | 揭开全部安全格即通关，踩雷失败；插旗不是胜利必要条件       |
| 标记     | 旗帜是玩家笔记，不作为提示推理的正确性证据                 |
| 操作     | 支持右键插旗、触屏揭格／插旗模式和键盘操作                 |
| 提示     | 分层展示观察位置、推理和行动原因；从第一层起即计为使用提示 |
| 查看答案 | 展示完整盘面，进入学习状态，本轮不计通关                   |
| 规则帮助 | 查看规则文字不影响无提示记录                               |

## 解锁与记录

章内可自由选关；通过当前章任意四关，或通过第五关结业题，解锁下一章。保留“已通关”和“无提示通关”两种结果，辅助重玩不会清除已有无提示徽章。

成功时提交胜利记录，分数为 0；核心成长反馈是关卡完成与无提示徽章，而非积分排行。进度通过当前玩家档案保存，并兼容已有浏览器进度。

## 产品边界

固定盘面可以重试学习，不承诺每次开局换题。失败或查看答案不能获得通关标记；不能把“插满旗帜”解释为已完成推理。

# 俄罗斯方块产品设计

游戏标识：`tetris`。状态：当前实现说明；核对日期：2026-09-30。

面向产品讨论、功能变更与回归评审。以下规则来自现有入口、实现及已列出的测试定义；定位是对当前玩法的概括，不代表已确认的用户研究或历史设计动机。

## 定位与体验

在持续下落压力下安排方块，填满整行以消除并累积分数。当前为三档速度的单局生存挑战。

## 核心玩法

棋盘为 10 列 × 20 行。玩家移动、旋转或加速落下当前方块，锁定后生成下一块；满行消除，新方块生成位置被占用时本局结束。页面提供下一块预览与落点反馈。

| 操作或规则 | 当前行为                                                 |
| ---------- | -------------------------------------------------------- |
| 键盘       | 左右平移、上键旋转、下键软降、空格硬降；页面另有操作按钮 |
| 暂停       | 暂停后停止下落，继续后恢复；重新开始清空棋盘与分数       |
| 消行得分   | 一次消除 1/2/3/4 行分别得 100/300/500/800 分             |
| 降落得分   | 主动软降每格 1 分，硬降每格 2 分                         |

## 难度与节奏

| 难度 | 初始下落间隔 | 加速条件               | 最小间隔 |
| ---- | ------------ | ---------------------- | -------- |
| 简单 | 700 毫秒     | 每消除 10 行减 30 毫秒 | 280 毫秒 |
| 中等 | 500 毫秒     | 每消除 10 行减 30 毫秒 | 180 毫秒 |
| 复杂 | 330 毫秒     | 每消除 8 行减 22 毫秒  | 100 毫秒 |

## 结束与边界

结束时提交完成记录，包含累计分数和耗时；没有关卡通关或局内存档。当前旋转会尝试横向挪位避让障碍，不应据此宣称完整遵循某一竞技俄罗斯方块规则标准。

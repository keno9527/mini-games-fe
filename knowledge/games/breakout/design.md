# 打砖块产品设计

游戏标识：`breakout`。状态：当前实现说明；核对日期：2026-09-30。

面向产品讨论、功能变更与回归评审。以下规则来自现有入口、实现及已列出的测试定义；定位是对当前玩法的概括，不代表已确认的用户研究或历史设计动机。

## 定位与体验

通过移动挡板接球、控制反弹角度清除砖墙；在 30 个递进关卡中挑战，也可绘制并试玩自己的关卡。

## 战斗与关卡规则

| 元素 | 当前行为                                                                        |
| ---- | ------------------------------------------------------------------------------- |
| 胜利 | 清除全部可破坏砖块；不可破坏钢砖不计入清关目标                                  |
| 生命 | 开始时 3 条生命；所有球落下扣生命，清除临时效果并等待主动重新发球；生命耗尽失败 |
| 挡板 | 接触位置影响球的反弹方向；支持键盘、鼠标与触屏移动                              |
| 砖块 | 包含普通、耐久、爆破和不可破坏砖块；爆破可产生连锁反应                          |
| 道具 | 加宽挡板、多球、自动激光、减速、穿透球、额外生命；穿透球仍会被钢砖反弹          |
| 暂停 | 点击或空格发球，P／Esc 暂停；暂停冻结球、道具及效果时间                         |

## 挑战流程与记录

可选关挑战、过关进入后续关卡、失败重试当前关。画面累计分数与关卡战绩不同：每关成功或失败只记录该次尝试新增分数和有效游玩时间，避免把此前关卡累计分数重复结算。

关卡进度写入当前玩家档案；最后一关完成不会生成不存在的下一关。分数包含击砖与连击等反馈，具体数值以实现配置为准。

## 自定义关卡

提供 12 列 × 10 行画板，可从空白或内置模板创建，选择砖块笔刷绘制、擦除、撤销／重做、保存和试玩。保存使用浏览器本地存储；试玩至少需要一块可破坏砖。试玩不提交正式战绩和战役进度。

## 产品边界

自定义作品是当前浏览器保存的关卡，没有在线发布或多人协作功能。手机端打砖块是另一个独立入口，存档与产品边界见[手机端设计](../breakout-mobile/design.md)。

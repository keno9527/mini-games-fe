# 引力墓场产品设计

游戏标识：`gravity-graveyard`。状态：当前实现说明；核对日期：2026-09-30。

面向产品讨论、功能变更与回归评审。以下规则来自现有入口、实现及已列出的测试定义；定位是对当前玩法的概括，不代表已确认的用户研究或历史设计动机。

## 定位与体验

以牵引和斥力操纵轨道的动作叙事游戏。玩家操纵葬仪舰，让星骸与敌火成为完成任务的工具，并在三幕结束后作出结局选择。

## 核心循环

出航前选择已解锁的舰船和工具；进入当前幕，移动舰船、放置引力圣印、调整星骸与炮火轨道；完成仪式后选择局内模块，再推进下一幕。舰体耗尽即失败。

| 阶段              | 玩家目标                                                           |
| ----------------- | ------------------------------------------------------------------ |
| 第一幕 · 静默墓场 | 将星骸低速送入右侧葬环                                             |
| 第二幕 · 异端回声 | 安葬星骸，借引力反击异端舰                                         |
| 第三幕 · 拒葬圣堂 | 用星骸与炮火击破圣堂核心                                           |
| 幕间              | 选择能力模块，改变本局能力组合；第三幕完成后也先选择模块再进入结局 |

## 操作与反馈

鼠标左键放置牵引、右键放置斥力；页面提供移动、闪避、圣印回收等操作说明和触屏控件。引力改变物体运动轨迹；页面反馈舰体、仪式推进、得分与已保存生命。

## 结局与成长

| 结局         | 条件与结果                                           |
| ------------ | ---------------------------------------------------- |
| 完成葬仪     | 结束时可选，埋葬旗舰以保护航道；额外得 2300 分       |
| 打破圣轨     | 结束时可选，释放旗舰；额外得 1900 分                 |
| 成为第三枚锚 | 舰体至少 55、存档生命至少 140 时可选；额外得 3400 分 |

成功结局按顺序解锁尚未获得的模块、工具、舰船条目，记录在当前玩家档案中。局内模块与跨局解锁分别管理；不能把它描述为每过一幕永久叠加属性。成功或舰体归零失败均提交对应战绩。

## 产品边界

持久化的是可选内容解锁，不是当前战场的完整快照。叙事称谓对应当前页面文案，结局分数差异不等于经过确认的价值排序或平衡结论。

# 五子棋产品设计

游戏标识：`gomoku`。状态：当前实现说明；核对日期：2026-09-30。

面向产品讨论、功能变更与回归评审。以下规则来自现有入口、实现及已列出的测试定义；定位是对当前玩法的概括，不代表已确认的用户研究或历史设计动机。

## 定位与体验

在 15×15 棋盘上进行自由五子棋人机对战，或通过残局练习连续进攻。黑棋先行，五连及以上获胜，没有禁手。

## 模式与流程

| 模式         | 当前行为                                                                           |
| ------------ | ---------------------------------------------------------------------------------- |
| 人机对战     | 玩家执黑、电脑执白，提供简单、中等、复杂三档；轮流落子，成五获胜，满盘无胜者为平局 |
| 残局挑战     | 5 章共 30 关，目标从 1 手到 5 手取胜；全部关卡可自由选择                           |
| 残局进攻约束 | 每次非终结落子需形成下一手成五的冲四威胁；白棋优先获胜，否则封堵                   |
| 辅助         | 残局提供悔棋与三级提示，依次为战术、区域、参考解法                                 |
| 操作         | 棋盘点击落子；残局另支持键盘焦点落子、触屏拖动预览后抬手落子                       |

## 胜负与评价

人机胜／负／平分别记录 100／10／40 分。残局按黑方落子计手数，超出目标或不满足连续进攻要求可能失败；占用位置等非法输入不作为有效落子。

残局使用提示或悔棋仍可通关，记为辅助完成；两者均未使用记为独立完成，通关分别记录 60／100 分。独立完成记录不会被后续辅助通关降级。

## 进度与边界

残局完成结果和最近选关按玩家隔离，浏览器数据与玩家档案兼容。当前没有逐关解锁门槛，也不以唯一参考解作为判定标准；人机普通对局没有中途棋盘续玩。

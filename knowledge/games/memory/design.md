# 记忆翻牌产品设计

游戏标识：`memory`。状态：当前实现说明；核对日期：2026-09-30。

面向产品讨论、功能变更与回归评审。以下规则来自现有入口、实现及已列出的测试定义；定位是对当前玩法的概括，不代表已确认的用户研究或历史设计动机。

## 定位与体验

通过记住牌面位置，尽量用较少翻牌步数完成所有配对。当前是单局记忆挑战，没有倒计时失败条件。

## 功能与规则

| 场景     | 当前规则                                             |
| -------- | ---------------------------------------------------- |
| 难度     | 简单 6 对、中等 8 对、复杂 12 对；牌面成对出现并洗牌 |
| 开局     | 第一次翻牌开始计时；每翻开两张计 1 步                |
| 配对成功 | 两张相同牌保留为已匹配状态                           |
| 配对失败 | 短暂展示后盖回；等待结算期间不能翻第三张             |
| 完成     | 配对全部牌即获胜；得分为 `max(0, 1000 - 步数 × 10)`  |
| 重玩     | 重新洗牌或切换难度会重置本局；没有中途牌局存档       |

## 反馈与记录

页面展示翻牌步数和已配对数量。完成时按当前玩家记录胜利、分数和耗时；耗时不进入当前评分公式。

## 产品边界

难度改变记忆容量，评分仅按绝对步数扣分。不同对数下的得分不是经过难度归一化的成绩；已匹配牌不能再次参与配对。

# 折光回廊产品设计

游戏标识：`laser-mirror`。状态：当前实现说明；核对日期：2026-09-30。

面向产品讨论、功能变更与回归评审。以下规则来自现有入口、实现及已列出的测试定义；定位是对当前玩法的概括，不代表已确认的用户研究或历史设计动机。

## 定位与体验

光路解谜：通过旋转固定位置的镜面，让光束同时点亮全部水晶。用较少操作完成关卡，并通过重复挑战提高星级。

## 关卡与规则

当前共 9 关，按简单、中等、复杂各 3 关组织，逐关解锁。关卡固定发射器、镜面、水晶、墙体和分光器的位置，玩家改变镜面方向。

| 元素或操作 | 当前行为                                                       |
| ---------- | -------------------------------------------------------------- |
| 镜面       | 点击在两种斜向之间切换，改变反射方向，计一步                   |
| 墙体与边界 | 墙体吸收光束，光束离开棋盘即终止                               |
| 分光器     | 产生继续直行与顺时针转向的两条光路                             |
| 通关       | 所有水晶在当前光路中同时点亮                                   |
| 撤销与重置 | 撤销恢复前一镜面布局并减少步数；重置回到关卡初始状态           |
| 提示       | 将一面与参考解不同的镜面直接调整到参考方向；本局标记为使用提示 |

## 评价与成长

未用提示时，不超过参考步数获 3 星，超出不多于 2 步获 2 星，其余为 1 星；使用提示后本局最高 1 星。通关得分为 `星数 × 1000 + max(0, 250 - 步数 × 10)`。

保留每关最佳星数和最少步数，通关解锁下一关；这些最佳值分别保留，不要求来自同一次尝试。进度按玩家存入档案。

## 产品边界

胜利依据实际光路，不要求严格复制参考解。提示使用参考解，因此“提示给出的方向”不等于唯一解；没有耗尽步数导致失败的限制。

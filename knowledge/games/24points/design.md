# 24点产品设计

游戏标识：`24points`。状态：当前实现说明；核对日期：2026-09-30。

面向产品讨论、功能变更与回归评审。以下规则来自现有入口、实现及已列出的测试定义；定位是对当前玩法的概括，不代表已确认的用户研究或历史设计动机。

## 定位与体验

限时算术挑战：用四张牌的数值组成 24，在倒计时内连续解题积累分数。当前提供简单、中等、复杂三档；没有关卡地图或局内续玩。

## 功能与规则

| 场景       | 当前规则                                                                               |
| ---------- | -------------------------------------------------------------------------------------- |
| 开始挑战   | 简单 90 秒、中等 60 秒、复杂 40 秒；开始后本局不能切换难度                             |
| 题目       | 四张牌取值 1–13，A/J/Q/K 对应 1/11/12/13；复杂档提高抽到较大数值的概率                 |
| 作答       | 四个数各使用一次，可用加、减、乘、除及括号；可以键入表达式，或点击牌面与运算符按钮输入 |
| 正确答案   | 首次答对加 10 分，连续第二次加 15 分，第三次起每次加 20 分；随后自动换题               |
| 错误与跳过 | 计算结果不为 24 或跳过会清空连击；格式错误、用数错误显示提示；不直接扣分               |
| 无解题     | 随机出题不保证有解，页面会提示无解，玩家可跳过                                         |

## 结束与记录

倒计时结束显示总分；有当前玩家时提交一次完成记录，包含分数和本局时长。重新开始会清空本局分数和连击。

## 产品边界

计分体现连续作答，难度同时改变时长和出题分布。三档分数是否可直接比较尚无独立产品定义。输入控件实际支持 `*`、`/`，不能仅依据示例中的乘号认定支持所有数学符号。

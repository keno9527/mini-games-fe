# 坦克大战产品设计

游戏标识：`tank-battle`。状态：当前实现说明；核对日期：2026-09-30。

面向产品讨论、功能变更与回归评审。以下规则来自现有入口、实现及已列出的测试定义；定位是对当前玩法的概括，不代表已确认的用户研究或历史设计动机。

## 定位与体验

以守护老鹰基地为核心的像素坦克闯关游戏，提供单人作战、本机双人合作、关卡练习和自定义地图。玩家既要清除敌军，也要保护基地，个人存活不是唯一目标。

## 模式与内容

| 模式       | 当前行为                                             |
| ---------- | ---------------------------------------------------- |
| 单人作战   | 从战役起点或已保存进度开始，连续挑战后续关卡         |
| 双人合作   | 双手柄在本机加入，合作守护同一基地；不是网络联机     |
| 关卡练习   | 选择关卡，完成该关即结束，不连续推进整段战役         |
| 自定义地图 | 从编辑器或地图库启动单图试玩，结束后可重试或返回作品 |

战役有 Battle City 的 35 关与 Tank A 的 50 关。两套战役共享战斗机制，关卡地图及敌军配置以各自数据定义为准。

## 战斗、成长与胜负

| 规则       | 当前行为                                                                    |
| ---------- | --------------------------------------------------------------------------- |
| 目标       | 清除本关敌军后过关；战役推进到末关完成后获胜                                |
| 初始资源   | 每位玩家初始 10 条生命；内置关卡每关 20 辆敌军，同时活跃敌军上限 4 辆       |
| 失败       | 基地被毁或所有玩家耗尽生命即失败                                            |
| 升级       | 星星提升火力等级，跨关保留，死亡重生时重置；达到 20000 分有一次额外生命奖励 |
| 续关与重试 | 从关卡开头重建战场，重置本次分数、升级和计时；不是恢复中断时的战场快照      |

地形包括可逐步击碎的砖墙、钢墙、水面、草丛与冰面。钢墙通常阻挡炮火，高等级火力可破坏命中部分；冰面产生滑行，草丛遮挡视线，船装备允许玩家通过水面。

## 道具

带奖励的敌军触发道具掉落；内置每关第 4、11、18 辆为奖励敌军，装甲奖励敌军首次受击即掉落。拾取道具加 500 分，场上同时最多保留一个道具。

| 类别         | 效果                                                 |
| ------------ | ---------------------------------------------------- |
| 星星／坦克   | 拾取者升级火力／增加一条生命                         |
| 头盔／装甲   | 临时无敌／抵挡一次敌弹，装甲不叠加                   |
| 船           | 拾取者可通过水面，仍受墙体、基地、其他坦克和边界阻挡 |
| 手雷         | 清除场上可作用的敌军，不追加击杀分                   |
| 计时器／铲子 | 临时冻结敌军／重建并强化基地外围墙体                 |

船与装甲在换关或重生时清除；无水地图的船奖励会替换为手雷。个人装备不保护基地。

## 双人合作与输入

双方独立控制、生命和火力升级，共享分数与基地。队友彼此阻挡移动，但玩家子弹不伤害队友；个人道具作用于拾取者，全局道具影响共同战场。一人淘汰后另一人可继续，过关和加命奖励不会自动复活已淘汰队友。

单人可使用键盘、手柄或触屏；双人需要显式加入和设备绑定。手柄断开或页面失焦后的暂停、重连与继续由大厅及运行时管理，设备连接不等于已经加入玩家槽位。页面提供暂停、声音、帮助和全屏操作。

## 地图创作

支持从空白或经典地图副本开始，绘制地形、配置敌军队列、保存、复制、删除、导入／导出 JSON 及试玩。基地和出生位置受保护；阻塞通路等可玩性问题显示警告，与格式不合法区分。

作品与编辑草稿保存在当前浏览器。导入校验格式、尺寸、地形、保护区域和敌军队列；不合法内容不应覆盖已有作品。试玩使用独立地图副本，不修改原始模板，也不提交正式战绩。

## 进度、成绩与边界

战役进度按当前玩家、战役和单人／双人模式隔离，保留最远到达关卡。战役选择属于浏览器偏好。结算记录包含战役、模式、到达关卡、得分、耗时和胜负；练习标记为 practice，自定义地图不提交。

双人战绩归属当前选择的玩家档案，不是两份独立玩家成绩。关卡进度写入失败会有提示；地图与草稿没有跨浏览器同步能力。正式存档与公共成绩语义见[数据流](../../architecture/data-flow.md)和[领域实体](../../domain/entities.md)。

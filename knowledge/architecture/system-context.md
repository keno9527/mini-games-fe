# 系统上下文

## 边界

mini-games-fe 是一个**纯前端单页应用**，不包含任何后端服务。所有数据在浏览器本地闭环，唯一的外部网络依赖是 Google Fonts CDN 和一个外部游戏跳转链接。

## 上下文映射

| 外部角色 | 交互方式 | 说明 |
|----------|----------|------|
| 终端用户 | 鼠标 / 键盘 / 触屏 | 操作广场与游戏；部分重度游戏仅支持键鼠 |
| localStorage | 同步读写 | 唯一持久化层，无服务端同步 |
| Google Fonts | HTTPS 拉取 | `index.html` 中 `<link>` 引入，失败时回退到系统字体 |
| starlight-catcher | `window.open` 跳转 | 外部游戏，不在本仓库内，通过 `externalUrl` 声明 |

## 不做什么

- 不提供用户注册 / 登录 / 多人联机。
- 不做云端存档或跨设备同步。
- 不包含 BFF / API 网关；`src/api/` 是对 localStorage 的异步封装，并非真实 HTTP 客户端。
